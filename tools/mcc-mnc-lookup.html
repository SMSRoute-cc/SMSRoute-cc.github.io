What MCC and MNC actually are (E.212)

ITU-T Recommendation E.212 defines the Mobile Country Code (MCC): a 3-digit number that identifies the country (or a shared territory, or a small set of international/satellite operators) a mobile network is registered in. The first digit groups codes by region — 2 for Europe, 3 for North America and the Caribbean, 4 for Asia and the Middle East, 5 for Australia and Oceania, 6 for Africa, 7 for South and Central America, 9 for worldwide/satellite — but it is not a precise continent map, just an administrative grouping. A country can hold more than one MCC once its subscriber base outgrows a single block: the United States has seven (310-316), India has two (404 and 405), the United Kingdom has two (234 and 235).

The Mobile Network Code (MNC) is a 2- or 3-digit number issued underneath a given MCC to tell individual operators apart. MCC and MNC together form the "MCC-MNC tuple" that uniquely names a carrier — written as 262-01, or squashed together as 26201 in places that expect a fixed-width field. That tuple, in turn, is the first 5-6 digits of a SIM's IMSI (International Mobile Subscriber Identity): MCC + MNC + MSIN (the subscriber-specific remainder). A single brand can hold several MNCs at once for historical reasons (mergers, technology-specific blocks, regional licenses) — Germany's O2 and Vodafone both do — so "one carrier, one code" is not a safe assumption either.

Where MCC-MNC shows up in SMS and voice routing

In SMPP-based SMS delivery, an aggregator or SMSC uses the destination MCC-MNC to pick a route: which underlying carrier connection to hand a message to, and what that route costs. Delivery receipts (DLRs) can carry MCC-MNC-derived routing metadata about which network actually accepted the message, which is one of the more reliable per-message signals available without a dedicated lookup. HLR (Home Location Register) queries go further: a live HLR dip returns the MCC-MNC of the network a subscriber is currently registered on, right now, which is the only way to get a trustworthy answer for a specific number rather than an assigned-block guess. On the SIM side, the IMSI baked into a device at manufacture starts with the MCC-MNC of the home network the SIM was issued by — useful for identifying a SIM's origin, not for identifying where a number currently terminates after porting.

Worked example: decoding 262-01

Take the code 262-01, or 26201 squashed. The first three digits, 262, are the MCC: region digit 2 (Europe), and 262 specifically is assigned to Germany. The next two digits, 01, are the MNC: within Germany's 262 block, 01 is assigned to Telekom Deutschland GmbH (Deutsche Telekom). So 262-01 names one specific network: Telekom in Germany, distinct from 262-02 (Vodafone D2 GmbH) or 262-03 (O2 / Telefonica Germany) sitting right next to it under the same country code. If that same 5-6 digit sequence shows up as the MCC-MNC in an IMSI prefix or an HLR response, it is telling you the subscriber's SIM (or their live registration, for an HLR dip) is associated with Telekom — not that every +49 number beginning that way is still on Telekom's network today, since porting can move the live network without changing the number.

Frequently asked questions

What is an MCC?

A Mobile Country Code (MCC) is a 3-digit code defined by ITU-T Recommendation E.212 that identifies the country a mobile network operator is registered in. It is combined with a Mobile Network Code (MNC) of 2 or 3 digits to uniquely identify a specific carrier — for example 262-01 for Telekom Deutschland in Germany. MCC-MNC pairs appear inside the IMSI on a SIM, in HLR lookup responses, and in SMPP routing and delivery receipt (DLR) data.

Can MCC-MNC tell me a number's current network?

No. An MCC-MNC pair shows which network a code block was originally assigned to, not which network is currently serving a specific phone number. Number portability (MNP) lets a subscriber keep their number after switching carriers, so a number can carry one operator's code while actually running on a different operator's network today. The only reliable way to find a number's live network is a real-time HLR lookup, not a static allocation table.

What MCC is Germany?

Germany's Mobile Country Code is 262. Every network operating in Germany shares that MCC and is told apart by its Mobile Network Code: 262-01 is Telekom, 262-02 is Vodafone, and 262-03 is O2 (Telefonica), among others.
