SMSRoute open data

Dated JSON snapshots of what SMSRoute publishes: per-destination SMS rates (including the competitor columns as published on the live price page), sender-registration rules by country, and coverage facts. Free to reuse with attribution (CC-BY 4.0). No API key.

  • prices.json - published per-destination rates
  • countries.json - sender-registration rules by country
  • coverage.json - coverage and payment facts
  • openapi.yaml - machine description of this dataset

What this is not: the live sending API (that is api.smsroute.cc and needs an account). Rates for destinations beyond the published sample are shown live after login; they are deliberately not republished here to avoid stale data.
