South Korea: SMS delivery facts

SMS delivery to South Korea uses calling code +82. Sender IDs for bulk messaging require pre-registration under the KISA regime, which runs the carrier verification system. Korean Hangul forces UCS-2 encoding, yielding 70-character single segments or 67 when concatenated.

Frequently asked

Do sender IDs need pre-registration for South Korea SMS?
Yes. Sender numbers/IDs used for bulk messaging must be pre-registered; KISA operates the sender number verification system used by carriers.

Hangul forces UCS-2, so single segments hold 70 characters and concatenated segments hold 67.
